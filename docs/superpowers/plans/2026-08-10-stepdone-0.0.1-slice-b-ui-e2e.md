# StepDone 0.0.1 Slice B — UI & E2E Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 按设计稿结构对齐实现可演示 Web UI（六步全可点 → 预览付费 → 轻编辑/质量/能力 → 假导出），并用 Playwright 锁住主链路。

**Architecture:** `apps/web` App Router；营销页 RSC；工作台 Client Components；TanStack Query 拉状态；Zustand 存游客草稿；SSE hook 听进度；调用 Slice A 已有 API，不在前端伪造付费/权益。

**Tech Stack:** Next.js 16.3、React 19、Tailwind CSS 4、React Hook Form、Zod、TanStack Query、Zustand、Tiptap（极简）、Playwright、ECharts（能力雷达）。

**Spec:** `docs/superpowers/specs/2026-08-10-stepdone-0.0.1-vertical-slice-design.md`  
**Depends on:** Slice A 计划完成（API/Worker/支付可用）

## Global Constraints

- UI **结构对齐** `docs/ui/stepdone.0.0.1.png` 与 PRD 文案；主色专业蓝；非像素级
- 断点：mobile `<768`、tablet `768–1199`、desktop `≥1200`
- PC 工作台：左 240 / 中自适应 / 右 360；手机底栏 + AI Bottom Sheet
- 游客草稿仅客户端；登录后 `POST /api/projects`
- 自动保存：防抖 1s、失焦、切步、30s；冲突 UI「保留我的 / 用云端」
- AI 导师语气克制；一次一问
- 改 Next 约定前读 `node_modules/next/dist/docs/`
- 每个 Task 结束 commit

```tsx
async function pay(productCode: "STANDARD_PROJECT" | "PRO_PROJECT") {
  const order = await api<{ orderPublicId: string }>("/api/orders", {
    method: "POST",
    body: JSON.stringify({ projectId, productCode }),
  });
  if (!order.success) throw new Error(order.error.message);
  const confirmed = await api("/api/payments/mock/confirm", {
    method: "POST",
    body: JSON.stringify({ orderPublicId: order.data.orderPublicId }),
  });
  if (!confirmed.success) throw new Error(confirmed.error.message);
}
```

支付失败提示：**不得清空项目**；提供重新支付。
